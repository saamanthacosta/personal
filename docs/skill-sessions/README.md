# Skill sessions

Per-session reports for any run that emits the shared JSONL event stream defined in [`.agents/skills/skill-sessions/SCHEMA.md`](../../.agents/skills/skill-sessions/SCHEMA.md).

## Convention

- One file per run, named `<UTC-ISO-timestamp>-<change-or-scope>.md`.
- Each file starts with YAML frontmatter (`skill`, `change`, `branch`, `started_at`, `ended_at`, `status`).
- The file body holds the verbatim timeline block emitted in chat, plus a `## Sources` and `## Evidence` section appended when the run finishes.

## Index

`INDEX.md` is regenerated by:

```bash
node .agents/skills/skill-sessions/bin/format-sessions.mjs
```

The index lists every session sorted by `started_at` (newest first), with one row per run. Treat it as the entry point when auditing past runs.

## Helpers

- `bin/format-sessions.mjs` — regenerate `INDEX.md` from per-run files.
- `bin/render.mjs` — render a JSONL event stream to the chat timeline block.
- `bin/append-event.mjs` — append events to a session file; finalizes frontmatter on session end.

These scripts are intentionally zero-dependency and live under `.agents/skills/skill-sessions/bin/`. Never write session data anywhere else.
